To solve this task, we need to fetch the historical data of the AAPL stock for the last 30 days. We can use the yfinance library in Python to do this. The library allows us to download stock data from Yahoo Finance.

Here is the plan:
1. Install the yfinance library.
2. Fetch the historical data for AAPL for the last 30 days.
3. Find the lowest and highest prices in this period.
4. Calculate the profit if 200 stocks were bought at the lowest price and sold at the highest price.
5. Save the result to a file named apple_profit.txt.

Here is the Python code to do this:

```python
# filename: calculate_profit.py

import yfinance as yf
from datetime import datetime, timedelta

# Define the ticker symbol
tickerSymbol = 'AAPL'

# Get data for the last 30 days
end_date = datetime.now()
start_date = end_date - timedelta(days=30)

# Get the historical prices for this ticker
tickerData = yf.Ticker(tickerSymbol)
tickerDf = tickerData.history(period='1d', start=start_date, end=end_date)

# Find the lowest and highest prices
lowest_price = tickerDf['Low'].min()
highest_price = tickerDf['High'].max()

# Calculate the profit
stocks = 200
profit = (highest_price - lowest_price) * stocks

# Save the result to a file
with open('apple_profit.txt', 'w') as f:
    f.write(f'Profit: ${profit}\n')

print('The profit has been calculated and saved to apple_profit.txt.')
```

You can run this script with the command `python calculate_profit.py`.

Please note that you need to have the yfinance library installed. If it's not installed, you can install it with the command `pip install yfinance`.
