Sure, you can use a simple shell script to create 10 empty text files in a directory. Here is the script:

```sh
# filename: create_files.sh

#!/bin/bash

for i in {1..10}
do
   touch "file${i}.txt"
done
```

To run this script, you need to save it to a file named `create_files.sh`, give it execute permissions, and then run it. Here are the commands to do that:

```sh
chmod +x create_files.sh
./create_files.sh
```

This script will create 10 files named `file1.txt`, `file2.txt`, ..., `file10.txt` in the current directory. If you want to create the files in a different directory, you can change the `touch "file${i}.txt"` line to `touch "/path/to/directory/file${i}.txt"`, replacing `/path/to/directory/` with the path to your desired directory.
