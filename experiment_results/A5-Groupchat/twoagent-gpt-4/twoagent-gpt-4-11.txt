Sure, we can use the matplotlib library in Python to plot the graph of y = sin(x) in the range of [0, 2pi] and save it as a png file. Here is the Python code to do that:

```python
# filename: plot_sinx.py

import matplotlib.pyplot as plt
import numpy as np

# Create an array of x values from 0 to 2pi
x = np.linspace(0, 2*np.pi, 100)

# Create an array of y values using numpy's sin function
y = np.sin(x)

# Create a figure and a set of subplots
fig, ax = plt.subplots()

# Plot y = sin(x)
ax.plot(x, y)

# Set the x and y axis labels
ax.set(xlabel='x', ylabel='sin(x)',
       title='Plot of y = sin(x)')

# Grid on
ax.grid()

# Save the figure as a png file
fig.savefig("sinx.png")

print("The graph has been saved as sinx.png")
```

You can run this script by typing `python plot_sinx.py` in your terminal. This will create a png file named "sinx.png" in the same directory.
