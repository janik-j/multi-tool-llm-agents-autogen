To extract the latest PR from the FLAML repo, we can use the GitHub API. The API endpoint for pull requests is `https://api.github.com/repos/{owner}/{repo}/pulls`. We will use the requests library in Python to send a GET request to this endpoint. The response will be a JSON object containing information about all open pull requests. We will sort this list by the 'created_at' field to find the latest PR. Finally, we will write the information about the latest PR to a file named 'flaml_latest_pr.txt'.

Here is the Python code to do this:

```python
# filename: get_latest_pr.py

import requests
import json

# Define the API endpoint
url = 'https://api.github.com/repos/microsoft/FLAML/pulls'

# Send a GET request to the API endpoint
response = requests.get(url)

# Check that the request was successful
if response.status_code == 200:
    # Parse the response as JSON
    data = response.json()

    # Sort the list of PRs by the 'created_at' field
    data.sort(key=lambda x: x['created_at'], reverse=True)

    # Get the latest PR
    latest_pr = data[0]

    # Write the information about the latest PR to a file
    with open('flaml_latest_pr.txt', 'w') as f:
        f.write(json.dumps(latest_pr, indent=4))
else:
    print(f'Error: {response.status_code}')
```

You can run this script by executing `python get_latest_pr.py` in your terminal. After running the script, you should see a file named 'flaml_latest_pr.txt' in the same directory. This file will contain information about the latest PR in the FLAML repo.
