To draw the graph of y = sin(x) in the range of [0, 2pi] and save it as sinx.png file, you can use Python with matplotlib library. Here's the code to achieve this:

```python
# filename: sinx_plot.py
import matplotlib.pyplot as plt
import numpy as np

x = np.linspace(0, 2*np.pi, 1000)
y = np.sin(x)

plt.plot(x, y)
plt.xlabel('x')
plt.ylabel('sin(x)')
plt.title('Graph of y = sin(x)')
plt.grid(True)
plt.savefig('sinx.png')
plt.show()
```
